# ✅ FAQ

## Pourquoi pas npm ?
Pour rester accessible aux débutants.

## Peut-on utiliser en production ?
Ce n’est pas l’objectif. C’est un support d’apprentissage.

## Peut-on ajouter React / Vue ?
Non, sauf dans une branche expérimentale séparée.

## Puis-je adapter pour mes cours ?
Oui, selon les termes de la licence.
