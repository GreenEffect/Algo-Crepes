# 🎓 Intentions pédagogiques

Algo-Crêpes sert à introduire la programmation via une métaphore connue.

## Compétences travaillées

- variables
- conditions
- boucles
- fonctions
- classes
- async / await
- séparation UI / logique

## Public cible

- non développeurs
- étudiants débutants
- profils en reconversion

## Philosophie

On accepte :
✅ répétition
✅ verbosité
✅ simplification

On évite :
❌ patterns avancés
❌ magie implicite
❌ dépendances
