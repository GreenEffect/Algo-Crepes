# 🤝 Contribuer à Algo-Crêpes

Merci de ton intérêt pour le projet 🥞

Le but est pédagogique : la lisibilité et la simplicité priment sur la performance ou la sophistication.

## Principes importants

- Pas de dépendances externes
- JavaScript compréhensible par des débutants
- Pas de build system
- Nommage clair et commentaires encouragés

## Types de contributions acceptées

✅ Correction d’erreurs  
✅ Amélioration de la clarté pédagogique  
✅ Ajout d’exemples  
✅ Traductions  
✅ Amélioration de la documentation  

❌ Refactor complexe rendant le code moins accessible  
❌ Ajout de frameworks ou librairies

## Workflow

1. Fork
2. Crée une branche : `feature/ma-modification`
3. Commit avec message explicite
4. Pull request avec explication du pourquoi pédagogique

## Style de code

- indent 2 ou 4 espaces, mais cohérent
- noms explicites en français autorisés
- préférer la clarté à l’optimisation

## Besoin d’aide ?

Ouvre une issue avec :
- problème rencontré
- comportement attendu
- capture si interface
